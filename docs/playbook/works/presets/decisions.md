# Decisions of the work presets

| ID | Date | Decision | Who decided | Their words |
|----|------|----------|-------------|-------------|
| presets-1 | 2026-11-25 | The first version of presets is the core: a preset at user level (permission rules and skills), detected by the wizard `permissions` from the project's files and applied there, and a registry of which project uses which preset. Propagation of changes and discovery across repositories are later works, built on that registry. Chosen over all four parts in one work and over discovery first. | Andres Frei | Chose "Núcleo (Recomendado)" |
| presets-2 | 2026-11-25 | The plugin ships no presets: the owner creates each one from a project already set up ("save this as preset cloudflare"), and it is kept at user level. Chosen over presets shipped by the plugin, which would be a list of tools (basics-24, basics-25). | Andres Frei | Chose "Los tuyos (Recomendado)" |
| presets-3 | 2026-11-25 | Presets and the registry of which project uses each live in `~/.claude/playbook/`, outside the repositories, so uninstalling the plugin keeps them. Chosen over `${CLAUDE_PLUGIN_DATA}`, which plugins-reference.md says "Claude Code deletes ... when you uninstall the plugin", and over a git repository of the owner. | Andres Frei | Chose "~/.claude/playbook/ (Recomendado)" |
| presets-4 | 2026-11-25 | A preset holds `allow`, `ask`, and `deny` rules, written to the project's `.claude/settings.json`, and skills and agents, placed in the project's `.claude/skills/` and `.claude/agents/`. MCP servers are out of this version. Chosen over rules and skills only and over adding MCP servers. | Andres Frei | Chose "Reglas + skills + agents (Recomendado)" |
| presets-5 | 2026-11-25 | A preset's skills and agents are copied into the project's `.claude/` and committed there, so the repository works alone on any machine; a change to the preset reaches each project by propagation, a later work. Chosen over a symlink to `~/.claude/playbook/`. | Andres Frei | Chose "Copia (Recomendado)" |
| presets-6 | 2026-11-25 | A new skill `presets` saves a preset from the project and applies one to it; the wizard `permissions` detects from the project's files a preset that fits and offers to apply it before its questions. Chosen over growing the wizard to save and apply, so each skill keeps one job (R17). | Andres Frei | Chose "Skill nuevo + wizard (Recomendado)" |
| presets-7 | 2026-11-25 | A preset names its signal files (such as `wrangler.toml`): Claude proposes them when the preset is saved and the owner confirms them. A script detects a preset by checking that its signal files exist in the project, deterministic and tested offline. Chosen over Claude judging the fit by reading the preset and the repository. | Andres Frei | Chose "Archivos señal (Recomendado)" |
| presets-8 | 2026-11-25 | The registry of applied presets lives only in `~/.claude/playbook/`, one entry per project path with its presets; the project holds no record. Chosen over also committing a line in the project. | Andres Frei | Chose "Solo en ~/.claude/playbook/ (Recomendado)" |
| presets-9 | 2026-11-25 | The owner accepts the spec of the work presets. | Andres Frei | Chose "Acepto (Recomendado)" |
| presets-10 | 2026-11-25 | Two applies at the same moment may lose one registry entry, since the registry is read and rewritten with no lock; the risk is accepted with no code, and a second apply restores the entry. Known case for the propagation work. Chosen over a lock around the registry's write. | Andres Frei | Chose "Aceptar el riesgo (Recomendado)" |
| presets-11 | 2026-11-25 | Replaced by presets-12. The work presets is delivered with no new version: pushed, opened as a pull request, and merged, with no tag. Chosen over the recommended MINOR, 5.7.0, by the line `Versioning:` of `technology.md`. | Andres Frei | Chose "Sin versión" |
| presets-12 | 2026-11-25 | Replaces presets-11. The work presets is released as 5.6.1, in the line 5.6, as an exception to the line `Versioning:` of `technology.md`, which makes a new skill MINOR. Chosen over moving the published tag v5.6.0 and over 5.7.0. | Andres Frei | Asked "quiero que sea parte de la version 5.6 que subimos hace un rato"; chose "5.6.1 como excepción (Recomendado)" |
