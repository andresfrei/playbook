# Decisions of the work build-mode

| ID | Date | Decision | Who decided | Their words |
|----|------|----------|-------------|-------------|
| build-mode-1 | 2026-11-22 | Open the work `build-mode`: two ways of working, `main` (build in the main session, `/clear` and `/model sonnet` between units, as session-cost-1 left it; the default when no line is set) and `delegate` (the main session on Opus defines, writes a brief, and verifies; a subagent on Sonnet builds each unit). The mode is the developer's choice, not the project's: it never goes in the project's `CLAUDE.md` nor in the wiki. | Andres Frei | "si, es la idea, pero esa desicicion no es parte del proyecto, es parte de como el desarrollador quiera trabajar para ahorrar token o eficiencia de tiempo y toma de desiciones quizas" |
| build-mode-2 | 2026-11-22 | The mode is one line in `~/.claude/CLAUDE.md` (every project of the developer) or in the project's `CLAUDE.local.md` (an exception for one project, gitignored). memory.md says the files are "concatenated into context rather than overriding each other" and that Claude "may pick one arbitrarily" on a contradiction, so `rules.md` states that the local line wins over the global one. | Andres Frei | Asked "¿Vamos con global más local, y que gane el local?": "si, vmaos con esa" |
| build-mode-3 | 2026-11-22 | In `delegate` mode, a plugin agent `builder` with `model: sonnet` builds one unit from a brief, as `reviewer` reads one change; `rules.md` says what the main session does: write the brief (the spec, the unit, the files to read by path, not copied, and its check), run `builder`, then verify with the tests and the diff, and `reviewer` when the change is risky. No new skill. | Andres Frei | Option chosen: "Agent + rules line (Recommended)" |
| build-mode-4 | 2026-11-22 | `define` asks the mode once, in a dialog, when neither `~/.claude/CLAUDE.md` nor `CLAUDE.local.md` holds the line, and asks where to write it; the developer changes it later by asking. | Andres Frei | Shown this as point 4 of the design, then asked "¿Esta es la idea que tenés en la cabeza?": "si, es la idea" |
| build-mode-5 | 2026-11-22 | Replaces the names in build-mode-1 to build-mode-4. One family of names: the line is `Build mode: main` or `Build mode: builder`, and the value names what builds the unit: the main session, or the agent `builder`. The words "Work mode" and "delegate" are not used. | Andres Frei | Asked "¿Vamos con `Build mode: main \| builder`?": "ahí si me gusta" |
| build-mode-6 | 2026-11-22 | The owner accepts the spec of `build-mode`: one unit, the six changes it lists, with the two points it marked Proposed (`define` in `builder` mode recommends staying on the current model; `close` keeps recommending `/clear` in both modes). | Andres Frei | Asked "¿Aceptás el spec de build-mode así, con los dos puntos propuestos de `define` y `close`?": "acepto" |
