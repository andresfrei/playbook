# Decisions of the work permissions-wizard

| ID | Date | Decision | Who decided | Their words |
|----|------|----------|-------------|-------------|
| permissions-wizard-1 | 2026-11-25 | Open the work: a wizard that asks the owner what Claude may do and writes the answers into Claude Code's settings, attribution in commits and pull requests among them. It lives in the playbook plugin, for any project; playbot keeps `bot-permissions` for its bot files and may reuse the wizard later. Chosen over extending playbot's `bot-permissions` and over one wizard shared by both plugins. | Andres Frei | Asked "quiero que sea opcional, de hecho quiero que tengamos un wizard de permisos y que cosas si habilitar y que cosas no"; chose "Playbook (Recomendado)" |
| permissions-wizard-2 | 2026-11-25 | The wizard sets four things, each a Claude Code setting: `attribution` in commits and pull requests; `allow` rules for the project's own commands, proposed from its files and checks; `ask` rules before commands that destroy work; `deny` rules that keep Claude from reading or editing secrets. | Andres Frei | Chose "Atribución (Recomendado), Permitir sin preguntar, Preguntar antes, Bloquear secretos" |
| permissions-wizard-3 | 2026-11-25 | The wizard writes by kind: `allow`, `ask`, and `deny` rules go to the project's `.claude/settings.json`, which serves whoever opens the project; `attribution`, the owner's preference, goes to `~/.claude/settings.json`. It says where each one goes before writing. Chosen over asking the file each time and over always `.claude/settings.local.json`. | Andres Frei | Chose "Según el tipo (Recomendado)" |
| permissions-wizard-4 | 2026-11-25 | The wizard runs on the owner's request, as `/playbook:permissions`, and `audit` offers it once when it adopts a project. Chosen over request only and over a notice in every new session. | Andres Frei | Chose "A pedido + al adoptar (Recomendado)" |
| permissions-wizard-5 | 2026-11-25 | The wizard writes through a POSIX script of the plugin that uses `jq`: it adds rules without duplicating them, never removes one, writes atomically, and has an offline test. `jq` becomes a requirement of the plugin; when it is missing, the wizard says so and writes nothing. Chosen over Claude editing the JSON with Edit. | Andres Frei | Chose "Script con jq (Recomendado)" |
| permissions-wizard-6 | 2026-11-25 | The owner accepts the spec of the work permissions-wizard. | Andres Frei | Chose "Acepto (Recomendado)" |
