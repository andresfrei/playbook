| basics-13 | 2026-11-21 | Every action has a weight, and the weight says whether the owner is asked. Light: a record that follows from a command the owner ran and that git undoes, such as the line "Last audit", a unit marked Done, a "Replaced by" mark at close, or a link the check flags; it is done without asking, since running the command is the yes. Medium: anything that states how the product is or how Claude behaves, such as resolving a contradiction, a new rule, a technology, or accepting a spec; it is asked once, and the answer is the decision, with no separate confirmation. Heavy: what cannot be undone or leaves the machine, such as push, pull request, merge, release, or secrets; a hook asks. When unsure between light and medium, it is medium. `audit` writes "Last audit" without asking. The README recommends deny rules for local destructive commands, such as `git reset --hard`, `rm -rf`, and a forced push, since no hook covers them. | Andres Frei | "audit no necesita pregutnarme, si corro, debe grabar.. pensemos esto"; "si, registralo con el desempate y el punto 3 al README" | none | | definition | as recommended |
