# Stage 3 — Skills

The agent has the skills it needs for each decided technology before it writes code with it.

## Steps

1. For each technology in `03-technology/`, read the names and descriptions of the skills available in the session and of the skills kept in the project's repository. Note which one covers it.
2. For each technology that no skill covers, propose one of these, with the reason in one line:
   - a skill that exists and can be installed, after reading it;
   - a skill written for this project;
   - no skill needed.
3. Install or write a skill only after the owner approves it.
4. Keep a skill that serves only this project in this project's repository. Never change a general skill to fit one project.
5. Write `04-skills/`: one table with the technology, the skill, where the skill lives, and when it is used.

## Project already started

Write the skills the project already has. Propose a skill only for a technology that has none.

## Closing condition

- Every decided technology has a row: a skill, or "no skill needed".
- The skills the owner approved are in place.
- The owner accepts the list.
