# Stage 4 — Design system

The visual language is decided before any screen is built.

## Steps

1. When the product has no interface, ask the owner to close the stage as not applicable, and stop here.
2. Read in the product pages who uses the interface, on which devices, and for what.
3. Propose the visual identity: the colours and what each one is for, the typefaces, how dense the screens are, and the light and dark modes.
4. Define the tokens: the named values the code uses for colour, type, spacing, and shape.
5. Define the patterns: the components that the product's flows repeat, each with its states.
6. Record each choice the owner accepts as a decision.
7. Write `05-design-system/`: the identity, the tokens, and the patterns.

## Project already started

Write the identity, the tokens, and the patterns the code already has. Ask for a decision only for what changes.

## Closing condition

- The identity, the tokens, and the patterns are Decided, and the owner accepts them.
- Or the owner closed the stage as not applicable.
